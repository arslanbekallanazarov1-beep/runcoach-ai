# RunCoach AI - Product Documentation

## Название
RunCoach AI - персональный помощник для бегунов, помогающий анализировать тренировки и планировать последующие.

## Цель
Создать простое Android-приложение для начинающих и продолжающих бегунов, которое помогает им понимать свои тренировки и получать персонализированные рекомендации для следующей пробежки.

## Основная ценность продукта
После каждой пробежки пользователь получает понятный анализ тренировки и рекомендацию, что делать на следующей тренировке.

## Основной пользовательский цикл
Run → Analyze → Understand → Next Workout → Run again.

## Целевая аудитория
- Начинающие бегуны
- Любители бега, стремящиеся улучшить свои результаты
- Люди, которые хотят систематически развивать свои беговые способности
- Пользователи, которые хотят получать персонализированные рекомендации по тренировкам

## Проблемы, которые решает продукт
- Отсутствие структурированного анализа тренировок
- Сложность планирования последующих тренировок
- Невозможность отслеживать прогресс и тенденции
- Отсутствие персонализированных рекомендаций
- Сложность соблюдения тренировочного режима

## Основные функции MVP
- Регистрация пользователя
- Профиль бегуна с основной информацией
- Выбор цели тренировок (5K / 10K / Half Marathon / General Fitness)
- Указание количества тренировок в неделю
- Добавление пробежек с данными:
  - Расстояние
  - Продолжительность
  - Темп
  - Средний сердечный ритм
  - Максимальный сердечный ритм
  - RPE ( Perceived Rate of Exertion)
  - Продолжительность сна
  - Заметки
- Анализ тренировки
- Рекомендация следующей тренировки
- История тренировок
- Регистрация и вход с сохранением истории отдельно для каждого аккаунта
- Учёт сна и пульса в покое при расчёте следующей тренировки
- Прогноз погоды и совет по экипировке на русском и английском
- Озвучивание темпа и погодных советов
- Локальные макеты вызовов и дуэли с виртуальным пейсмейкером (без соревнований)
